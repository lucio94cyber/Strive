# 💪 STRIVE
### Fitness | Entrenamiento y superación

Una propuesta digital orientada al mundo del fitness, diseñada para transmitir energía, motivación y una identidad visual vinculada al entrenamiento y al bienestar.

## 🌐 Proyecto web

[**Visita Strive→**](https://strive25.netlify.app/)

## ✨ Características

- Presentación de la propuesta fitness.
- Diseño visual moderno y dinámico.
- Identidad orientada al entrenamiento.
- Navegación intuitiva.
- Adaptación a dispositivos móviles.

## 🎯 Objetivo del proyecto

Desarrollar una experiencia digital para una marca fitness, transmitiendo sus valores y ofreciendo una presencia online atractiva y funcional.

## 🛠️ Tecnologías

- HTML5
- CSS3

## 📂 Sobre este repositorio

Este proyecto representa una propuesta de sitio web para el sector fitness, con foco en la identidad visual, la experiencia del usuario y la comunicación digital.
